# 🚀 Инструкции по обновлению GitHub репозитория

## 📋 Команды для обновления репозитория

### 1. Инициализация Git (если еще не сделано)
```bash
cd "/Users/maloy/Desktop/Недвижимость Эдик"
git init
git remote add origin https://github.com/IlyaKhar/Shtok.git
```

### 2. Добавление всех файлов
```bash
git add .
```

### 3. Коммит с описанием изменений
```bash
git commit -m "🎨 Обновление дизайна: мятно-зеленая цветовая схема

✨ Новые возможности:
- Строгая мятно-зеленая цветовая схема
- Стеклянные эффекты (glassmorphism)
- Убраны градиенты для более строгого вида
- Обновленная документация
- Технические характеристики
- Инструкции по деплою и обновлению

🎨 Дизайн:
- Основной цвет: #235347 (элегантный зеленый)
- Акцентный цвет: #8EB69B (мятно-зеленый)
- Стеклянные карточки с размытием
- Современные тени и эффекты

📚 Документация:
- README.md - основная документация
- DEPLOY.md - инструкции по деплою
- TECHNICAL.md - технические характеристики
- UPDATE.md - инструкции по обновлению
- ABOUT.md - информация о проекте
- LICENSE - лицензия MIT"
```

### 4. Отправка в репозиторий
```bash
git push origin main
```

## 🎯 Рекомендуемые теги для коммитов

### По типу изменений:
- `🎨` - Изменения дизайна/стилей
- `✨` - Новые возможности
- `🐛` - Исправления багов
- `📚` - Документация
- `🚀` - Деплой/релиз
- `🔧` - Конфигурация
- `📱` - Мобильная оптимизация
- `⚡` - Производительность

### По важности:
- `feat:` - Новая функциональность
- `fix:` - Исправление бага
- `docs:` - Документация
- `style:` - Стили/форматирование
- `refactor:` - Рефакторинг кода
- `perf:` - Улучшение производительности
