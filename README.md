# 🏠 Shtok - Агентство недвижимости

Современный веб-сайт агентства недвижимости в Оренбурге с элегантным мятно-зеленым дизайном и стеклянными эффектами.

## ✨ Особенности

- 🎨 **Современный дизайн** - Мятно-зеленая цветовая схема с эффектами стеклянного морфизма
- 📱 **Полная адаптивность** - Оптимизирован для всех устройств
- ⚡ **Высокая производительность** - Быстрая загрузка и плавные анимации
- 🔍 **SEO оптимизация** - Структурированные данные и мета-теги
- 🎯 **UX/UI** - Интуитивный интерфейс с современными эффектами

## 🚀 Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/IlyaKhar/Shtok.git
   cd Shtok
   ```

2. **Откройте в браузере**
   ```bash
   # Просто откройте index.html в браузере
   open index.html
   ```

3. **Или используйте локальный сервер**
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js
   npx serve .
   ```

## 🔧 Настройка

### Изменение цветовой схемы
Отредактируйте CSS переменные в `assets/css/templatemo-villa-agency.css`:

```css
:root {
  --primary-color: #235347;      /* Основной цвет */
  --primary-dark: #163832;       /* Темный вариант */
  --accent-color: #8EB69B;       /* Акцентный цвет */
  --accent-light: #DAF1DE;       /* Светлый акцент */
}
```

### Добавление новых объектов
1. Откройте `properties.html`
2. Добавьте новый блок с классом `properties-items`
3. Укажите соответствующие фильтры (`adv`, `str`, `rac`)
